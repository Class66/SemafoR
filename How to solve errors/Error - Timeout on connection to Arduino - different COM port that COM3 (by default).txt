If the application cannot connect to the Arduino (timeout), set the serial port explicitly, for instance COM5.

1. Copy the .env.example file to .env (in the project root folder).
2. Set the port in the .env file:

ARDUINO_PORT=COM3

3. Restart the steering application (npm run steering).

When ARDUINO_PORT is empty or the .env file does not exist, the first available USB/COM serial port is used (it is not checked whether it is an Arduino), so with several serial devices always set the port explicitly.
